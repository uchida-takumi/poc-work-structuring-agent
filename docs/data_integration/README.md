## アーキテクチャ概要

```
ソースシステム群
  ERP(調達) | MES(生産) | WMS(在庫) | TMS(物流) | QMS(品質)
       ↓           ↓           ↓           ↓           ↓
  ─────────────────────────────────────────────────────
              データ取込レイヤー
       Apache Kafka（イベントストリーミング）
       Apache Airflow（バッチオーケストレーション）
  ─────────────────────────────────────────────────────
              ストレージレイヤー（ADLS Gen2）
   /raw/（原本） → /standardized/（標準化済み） → /curated/（AI向け）
  ─────────────────────────────────────────────────────
              提供レイヤー
   Azure Synapse（分析）| Azure ML（AI）| Power BI（KPI）
```
